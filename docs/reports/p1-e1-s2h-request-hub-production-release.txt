caller's live Membership. actor_user_id is always `auth.uid()`,

entirely separate columns from the linked Passenger row.

active before linking (ZW006 otherwise) — cross-org Passenger linking
is impossible by construction (the `where ... organization_id =
p_organization_id` clause). No unsafe reassignment path exists:
link_request_passenger is legal only while state='pending' (ZW004 once
accepted), matching the locked S2B decision that Passenger
reassignment on an already-converted Request is out of scope.

CONVERSION: pending+ready → Create Trip (create_trip, hardened by
P1-E1-S2F-A to require the Request's OWN linked passenger_id to be
