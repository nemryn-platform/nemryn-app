Goal 1 — richer seeded Operations Overview, same structure and live data:

  src/components/ui/Panel.tsx):
  - a header (icon tile, title, description, meta);
  - a hairline-separated body;
  - a quiet footer row for the card's action.
- Icon tiles across the Overview gained a faint inset ring in their own semantic family (iconToneClasses; existing
  tokens only).
- The lower panels (Upcoming Trips, Active Trips, Activity Log), Get started and the calm group are also raised for
  consistency.

Goal 2 — sidebar footer:
- The workspace is now a quiet card: icon tile · name (13px medium) over "Workspace" · Switch workspace when the
  person holds more than one workspace.
- The user row sits below it with its own padding: avatar · name over role.
- The grouping, items, widths, collapse and rail are unchanged.

Goal 3 — top vertical rhythm:

| Gap | Before → after |
|---|---|
| Page title / date → first section | 24 → 32px |
| Between the page's major sections (setup card, Brief, today's detail) | 24 → 32px |
| Brief heading → its stat row | 16px (unchanged, now explicit) |
| Between the Brief's cards | 24px |

Operating hours (when configured) moved from a loose line into the page header as a quiet second line under the
date, keeping the `operating-hours` testid.

Goal 4 — summary stat tiles (src/components/ui/StatTile.tsx):
- A vertical hierarchy:
  - top row: a 36px icon tile with the inset ring, plus a chevron only when a destination exists;
  - the value in a new `typography.metricValue` role (24px semibold, tabular);
  - the label (13px medium); an optional detail line.
- Tiles are raised. The values, labels, links and "Unavailable" handling are unchanged.
- `metricValue` is deliberately below `numericDisplay` (28px), which stays reserved for a view's single headline
  number (typography spec §4).

Goal 5 — the larger panels (spacing / hierarchy only; same rows, limits, copy, destinations and testids):
- Needs Attention:
  - The header carries the count badge.
  - The body opens with the "N trips need a driver" line.
  - Each row gets a fixed time column, then passenger + reason badge, route, explanation, and the row's action
    (Assign / Open Trip).
  - "+N more in Dispatch" moves to the footer.
- Requests awaiting review:
  - The count uses metricValue; the text is still "1 request" (a real space kept).
  - The oldest-request and accepted-not-scheduled facts sit in an inset list.
  - Review requests moves to the footer.
- Active Now / Next Departures:
  - Header plus a hairline body. Rows have a time column, then passenger over route, then the status (Active Now
    keeps its info dot + label).
  - "View today's trips" moves to the footer. Empty states are unchanged (compact).
- The same anatomy applies to the Tomorrow / Standing-orders (Recurring care) / Proof of service / Drivers blocks
  (shared CompactBlock).

Goal 6 — empty-workspace page: the same direction; only the setup card and Get started are raised. No other change.

Goal 7 — preserved:
- the deep graphite shell;
- graphite primary buttons;
- Geist Sans;
- 8px controls and 8px card radius;
- the sidebar grouping;
- the responsive behaviour (256 / 64 / rail);
- the 390px notice.

Goal 8 — duplicate-h1 error state: RESOLVED.
- Cause: the Overview / Dispatch / Trip Detail / Request Detail page headers (h1 + actions) were rendered by the
  layout (OperationsLayoutClient → OperationsShell `pageHeader` slot). The in-shell error boundary replaces only the
  page segment, so a failing page would have shown the layout's h1 and the error panel's h1.
- Fix:
  - The four headers now live in src/components/operations/OperationsPageHeaders.tsx and are rendered BY THE PAGES,
    in every branch, including their "unavailable" / "couldn't load" states.
  - The layout and shell render no h1 at all (the `pageHeader` slot was removed).
  - An error boundary therefore replaces the page's h1 together with the page.
  - The h1 text, the actions (Export Day Sheet / New Trip), the testids (`page-header`, `export-day-sheet-button`)
    and the Dispatch day-following description are unchanged.
