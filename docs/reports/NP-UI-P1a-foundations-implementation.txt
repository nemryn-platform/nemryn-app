10. DEVIATIONS, FINDINGS AND UNRESOLVED ISSUES
======================================================================
Deviations (disclosed; all minimal):
1. NemrynFormEditor.tsx: `<a href="/operations/settings/services">` became `<Link href="…">`, with the same
   destination, text and style.
   - Cause: the new /operations/[...missing] catch-all makes next/no-html-link-for-pages treat every /operations/*
     href as an app page, which turned this pre-existing anchor into a lint ERROR.
   - The only behavioural difference is client-side navigation instead of a full reload.
2. tests/shared/cdp.mjs: focus emulation + Page.bringToFront before each navigation.
   - Cause (measured): after keyboard focus left the page for browser UI, headless Chrome reported the tab as
     visibilityState=hidden with no requestAnimationFrame. React 19 reveals streamed Suspense content (the new route
     loading.tsx boundaries) on a frame, so the page stayed on its skeleton and s4-a11y's "Edit draft" keyboard check
     crashed.
   - Real users' foreground tabs are unaffected; a background tab reveals when viewed. The harness now emulates the
     foreground tab. No assertion changed.
3. tests/e2e/plus-quotes/run.mjs: after each reset the runner restarts the isolated stack's own Kong container and
   waits until auth answers through it.
   - Cause (measured): the reset restarted the auth container while Kong kept the old upstream, so every sign-in got
     502 ("doesn't match our records").
   - It touches only supabase_kong_<isolated project>. No assertion changed.
4. My own new UI-P1a test initially miscounted visible main landmarks (an element inside a hidden parent). I
   corrected it to checkVisibility() before acceptance. Not a product issue.
5. Work stays on branch np-ui-p0-architecture-audit (no UI-P1a branch was named; branch changes are prohibited).
Findings fixed during the phase:
- My first A3 approach (a second <main> element for the 390 px notice) broke `main` selectors at desktop widths:
  s3a A6 failed in the strict run. Replaced with role="main" on the notice; s3a is back to 31 / 31.
Environment notes:
- The isolated stack's supabase/seed.sql had gone missing (the first reset gave an empty DB, and the suite's
  seed-guard correctly refused). Restored from the repository copy.
Unresolved / out of scope (carried forward):

  raw checkbox / radio / time inputs. Planned for UI-P1b / P2.
