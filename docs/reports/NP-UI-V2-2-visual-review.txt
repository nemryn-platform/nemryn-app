3. OUTSTANDING VISUAL GAPS (documented, not fixed in V2-2)
----------------------------------------------------------
1. OWNER DECISION — detail-page h1.
   - Detail screens now use the display h1 ("Trip Detail") like every other Operations screen, per Brand Lock v2 §2.
   - P1b had made it a small label above the record name.
   - The record name stays the h2, in Geist, inside the summary, so the display face is only on the h1.
   - If the owner prefers the record name to read as the title, the alternative is a test-assertion change (H6 / H7 /
     E1 / A2 expect h1 = "Trip Detail" / "Request Detail"). That was not done.
2. Dispatch trip blocks:
   - unknown-duration trips keep the dashed outline and truncate "· Duration not set" in narrow blocks;
   - this is the existing duration semantics; the full text is in the title and aria-label.
3. Facilities, Drivers and Vehicles have no FilterBar or result count, because those lists have no search. Adding
   search would be a feature.
4. Log Request's breadcrumb still reads "Overview › Log Request": existing navigation copy, left as is.
5. Trip detail's "Record completion" stays a text-style action between the outline buttons and the teal Contact
   Driver: its existing variant, unchanged.
6. Shared-component reach:
   - the EmptyState and PanelHeader centring improvements also show on Growth / Quotes / Settings screens;
   - those screens' own recomposition remains V2-3.
