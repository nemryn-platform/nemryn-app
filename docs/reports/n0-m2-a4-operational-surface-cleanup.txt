5. PRIMARY-ACTION FINDINGS
-------------------------------
FOUND AND FIXED: `buttonStyles.ts`'s `secondary` variant was
`"bg-brand-care-navy text-white hover:brightness-110 active:brightness-95"`
— a SOLID Deep Graphite fill, visually indistinguishable from the
`primary` variant (`bg-action-primary-background text-action-primary-
foreground`, which resolves to the identical `#171a1d` hex). This
directly contradicts the LOCKED design-token specification
(docs/brand/nemryn/12-design-token-specification.md §2.4), which
defines `action.secondary` as a transparent/outline/ghost treatment
("`action.secondary.background`: transparent... Outline / ghost
button"), explicitly distinct from the solid-fill `action.primary` —
the spec's own governing principle is "one primary action per view."

Corrected `secondary` to the same transparent/border/text-primary
composition the codebase's own `outline` variant already correctly
uses (`border border-border-strong bg-surface-elevated text-text-
primary hover:bg-surface-hover`) — the spec defines no separate
`action-secondary-*` CSS custom properties, and `outline` already
implements that exact role under a different name, so reusing it
avoids introducing any new token.

Blast-radius check: `variant="secondary"` had exactly ONE call site in
the entire application — `src/app/foundation/page.tsx:130`, the
internal, non-product QA/component-showcase page. Zero real operational
or driver screens used it. This fix therefore carries zero production
visual change; it corrects the component's own definition so any
future consumer gets the spec-correct treatment automatically.

Every actual operational CTA — Create/Save/Assign/Continue/Update/
Confirm/Submit/Invite Driver, and every dialog's own primary submit
button — was confirmed to use either the default `variant="primary"`
(Button.tsx's own default) or an explicit `variant="outline"` for
de-emphasized actions (e.g. every dialog's "Cancel" button) or
`variant="destructive"` for genuinely destructive confirms (Cancel
Trip, No-Show). `DriverPrimaryAction`/`DriverNextTripCard` correctly
use `variant="primary"`. No CTA anywhere uses Signal Green as a default
action color — status meaning and action meaning remain fully separate,
confirmed by direct inspection of every `variant=` call site in
src/components/operations and src/components/driver (33 non-Cancel/
non-typography matches reviewed individually).
