ASSIGNMENT ATTRIBUTION
======================================================================
Trip Detail → Current Status, shown for every viewer. It is built from stored facts only: the trip's
trip_assignments rows (assigned_by, assigned_at, ended_at, end_reason), added to the existing Trip Detail read. The
pure deriveAssignmentAttribution (assignment-attribution-core.ts) produces:
  - "Assigned by <who> · Sep 25, 7:42 AM", for the current or last assignment.
  - "Reassigned by <who> · …", only when history proves it: an earlier row on the same trip ended at the moment this
    one began, with a non-trip-ending end_reason.
  - "Reason: <text>", only for an operator-entered end_reason. It never appears for reassigned / trip_completed /
    trip_cancelled / no_show.
  - assigned_by null gives "Assigned · <time>".
  - Nothing is inferred beyond the recorded action. History is never rewritten.
