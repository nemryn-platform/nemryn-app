6. DAY SHEET
======================================================================
  Architecture:
    - pure core src/lib/operations/day-sheet-core.ts: rows, sorting (pickup ascending, pickup-less last, ties by
      passenger), RFC 4180 CSV, filename, day parsing;
    - server src/lib/operations/day-sheet.ts getDaySheet(org, day): calls getDispatchBoardData(org, tz, day) -- the
      SAME day bounds and working set as the Dispatch screen, no second scheduling interpretation, no extra query;
      header facts (organization, full local date, timezone, generated timestamp) formatted in the org timezone.
  Scope: exactly what Dispatch shows for that day (non-terminal trips with a pickup in the org-local day). Completed,
    cancelled and no-show trips are excluded, as on Dispatch.
  Entry: header "Export Day Sheet" -> small menu ("Today's / Tomorrow's Day Sheet": Print / Save PDF, Download CSV).
    Overview exports today; Dispatch exports the selected day (?day=tomorrow -> Tomorrow; never silently Today).
  Columns (only): Pickup time, Appointment (when present), Passenger, Pickup, Destination, Driver ("Unassigned" when
    none), Vehicle, Status, Wheelchair equipment (Yes / No / blank -- already carried by the Dispatch data).
  NOT exported: phones, emails, requester data, assistance notes, instructions, notes, recovery notes, audit data,
    exception details, readiness reasons, notification data, ids, tokens.
  Print / PDF: authenticated route /day-sheet?day=today|tomorrow (src/app/day-sheet/page.tsx), OUTSIDE /operations so
    it has no sidebar / navigation; a screen-only toolbar (print:hidden) with Back to Dispatch, Download CSV and
    "Print / Save PDF" (window.print). Clean table; thead repeats on every printed page (table-header-group); rows
    break-inside-avoid; confidentiality line. No PDF dependency: the browser's Print -> Save as PDF.
  CSV: /day-sheet/csv?day=... (route handler): UTF-8 BOM, CRLF, header facts + column row + one row per trip;
    Content-Disposition attachment "<safe-org-name>-day-sheet-YYYY-MM-DD.csv"; Cache-Control private, no-store;
    X-Robots-Tag noindex.
  Zero-trip day: the control stays active; print view "No trips scheduled for this day."; CSV has headers only.
