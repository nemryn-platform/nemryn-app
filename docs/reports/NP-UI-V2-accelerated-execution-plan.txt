0. PRINCIPLES
-------------
- Four substantial releases, not a stream of styling-only patches. Each release is one branch → one PR → one
  production release, with a read-only production check afterwards.
- Change shared layers first (tokens → primitives → shell → pages). Token NAMES are kept, so most consumers move
  without per-file edits. No per-page colour / radius overrides.
- Presentation only:
  - no change to routes, server actions, queries, migrations, RLS / RPC, authorization, tenant isolation, quote /
    financial logic or print output semantics;
  - copy changes only where already approved (Brand Lock v1 §15 terminology), or as listed in the decision
    review.
- Every release runs the full regression gate (§6). Only the assertions that encode v1 visual values change, and
  only by recorded decision (§5).

7. SEQUENCING AND EFFORT (indicative)
-------------------------------------
- V2-1: the largest, because tokens + primitives + shell + Overview = the foundation.
- V2-2 and V2-3 can be prepared in parallel branches off V2-1, but are released in order.
- V2-4 is a QA / release step, with no new design.
- Each release stops for an owner review of the screenshots before commit, push, merge and production, matching
  the P1b / P2 controlled-release pattern.

8. RISKS
--------
- R1: A global token change in V2-1 alters every page at once. This is mitigated by the 29-route sweep in V2-1
  itself, not deferred to V2-2.
- R2: The display serif (D-1 = B) renders differently across operating systems. Option A avoids this but adds a font
  asset.
- R3: Teal primary vs the status green: the distinction is kept by hue (#006E69 vs #1F7A4D) and by status never
  being colour-only. This is verified by a review of Dispatch / Readiness screens.
- R4: Gradient panels are decorative only. Meaning is carried by the icon + text, never the tint.
- R5: The print output for quotes must not inherit the screen tints; this is covered by the s3c / o1 suites and a
  print capture.
- Open and unaffected: OD-Q13, OD-Q14, PD-10, PD-11.
