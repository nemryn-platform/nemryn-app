6. LOGO SIZING DECISIONS
------------------------------
Rather than hand-computing new per-site pixel dimensions, the
`width`/`height` props passed to each `<Image>` were set to the SVG's
own true intrinsic values (434 × 127 — exactly its viewBox), and each
site's existing Tailwind `className` (`h-auto w-60` for the six auth/
join cards, `h-auto w-32` for onboarding) was left completely
unchanged. Because Next.js's `<Image>` renders the underlying `<img>`
with `width`/`height` HTML attributes that establish the browser's
native intrinsic aspect ratio, and `h-auto` computes the rendered
height proportionally from a fixed CSS width, this guarantees a
mathematically exact, non-distorted 3.418 ratio at whatever width the
layout already specifies — with zero per-site arithmetic and zero risk
of a manual rounding error introducing drift.

Confirmed live via CDP `getBoundingClientRect()` on the rendered `<img
alt="Nemryn">` element on every one of the seven screens:
  - sign-in / sign-up / forgot-password / reset-password / auth-code-

    at the old 3.000 ratio — visual width preserved exactly, height now
    correctly derived rather than distorted)
  - onboarding: rendered at 128×37px, ratio 3.418 (previously 128×42px

No stretch, no crop, on any of the 14 desktop+mobile captures (§11/§12).
