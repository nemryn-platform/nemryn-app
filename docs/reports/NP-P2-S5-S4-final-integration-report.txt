serious). FAILING.

  (required ≥ 4.5:1).

  - Mark sent review (with and without DNC): "Valid until …";
  - the Estimates & Quotes directory: StatusBadge "cancelled" tone (bg-surface-secondary text-text-muted) on
    Withdrawn / Superseded.
- Reach: text-text-muted is used 282 times in src/; StatusBadge by 47 files.
- ENTRY REQUIREMENT R-U1: every text / background pair in the canonical tokens meets ≥ 4.5:1 (≥ 3:1 for large text),
  and A6 reports 0 serious / critical `color-contrast` violations on all quote surfaces.

U2 — Focus not restored after closing a dialog with its own buttons. WCAG 2.2 SC 2.4.3 Focus Order (A); related
SC 2.4.11 Focus Not Obscured (Minimum) (AA) and SC 3.2.1 On Focus. FAILING.
- Keyboard-activating Cancel (Edit draft, Record accepted) or Close (X) closes the dialog but leaves focus on <body>,
  not the trigger. Escape closes AND restores focus (passes).
- Observed cause: the shared src/components/ui/Dialog.tsx unmounts on a React state change, with no native
  dialog.close() and no explicit focus restore.
- Reach: Dialog is imported by 36 files (platform-wide).
- ENTRY REQUIREMENT R-U2: every Dialog close path (Escape, Cancel, Close X, backdrop, programmatic after success)
  returns focus to the invoking control, or to a documented successor when the trigger no longer exists.
